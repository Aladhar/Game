# Penance Carrier Godot Materials

Use this folder for extracted or hand-authored Godot `.tres` materials once the V2 GLB has stable UVs and texture names.

Recommended material split:

```text
penance_carrier_body_cloth.tres
penance_carrier_house_wood.tres
penance_carrier_metal_relics.tres
penance_carrier_paper_decals.tres
penance_carrier_glass_wax.tres
```

Each material should point at the matching texture set in:

```text
res://assets/textures/enemies/penance_carrier/
```
