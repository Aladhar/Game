# Tool Versions

Use these versions unless intentionally upgrading on a separate branch.

## Required

- Unreal Engine: 5.7.4
- Blender: 5.1
- OS target: Windows 11

## Rules

- Do not open/save assets in a different Unreal version without a backup branch.
- Do not batch-save Blender files from a different Blender version without visual QC.
- Upgrade engine/tools one at a time.
